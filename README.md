## 📗 DESCRIPTION

This mod gives you true fullbright by overriding Minecraft’s brightness cap (raised from 100 to 1500). It removes all darkness and shadows, making everything fully lit — regardless of time, biome, or dimension.

## 🧩 USAGE

* Press `B` to toggle between max brightness and previous brightness.

> To configure transitions, use the `/brightaura` command:
> * `/brightaura transition <true|false>` — enable or disable transition
> * `/brightaura transition_time <ticks>` — set the duration of the transition in ticks (e.g. 20 = 1 second)
